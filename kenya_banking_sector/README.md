# 🏦 Kenya Banking Sector Integrated Analytics

## Overview
This directory contains a set of banking-sector analytics assets and starter pipelines for the Kenyan market. It includes dbt models, dashboard prototypes, and ingestion examples for topics such as peer benchmarking, mortgage analytics, and macro-financial monitoring.

## What is included
- **dbt models** for staging and mart-style transformations.
- **Prototype dashboards** and CSV snapshots for local exploration.
- **Ingestion examples** for CBK-style and market-data sources.

## Current maturity
The repository snapshot is best viewed as a portfolio of analytics building blocks rather than a single fully deployed platform. Some folders are more complete than others, and several pieces are intended for local experimentation rather than production use.

## Suggested next steps
1. Pick one sub-project and run its local stack.
2. Replace the demo data with curated source files.
3. Expand tests and documentation around the models that matter most.
